## Project Identity

- **What:** a command-line converter from Shavian text (`U+10450`–`U+1047F`) to Tengwar, written as Alcarin Tengwar Private Use Area code points (`U+E000`–`U+E07F`). Shavian is the phonemic intermediate representation; English spelling is never consulted.
- **Owner:** Alex Regan. Alex reviews every decision about the mode; agents propose, Alex decides.
- **Stack:** Python 3.14, standard library only, run in place (not installed). npm is only a task runner. The PDF build has its own virtualenv.

## Rules of the Road

### The spec is the authority

- `spec/mode.md` defines what the engine does. **When the spec and the code disagree, the code is wrong.**
- To change behaviour: **spec first, then engine, then corpus**, then record why in an ADR.
- Statuses are `ADOPTED`, `PROVISIONAL` and `OPEN`. Open questions are in spec section 12.
- **The pull request is the approval gate.** A new or changed rule is `PROVISIONAL`, and its ADR `Proposed`, while its PR is open. Only when Alex says the PR is approved, add a last commit that sets them to `ADOPTED` / `Active` with **Review:** "Approved by merging PR #N". Merging is the approval, so `main` never holds a provisional rule. Never promote anything on your own judgment.
- Rule IDs look like `C-01`, `V-13`, `D-02`, `L-09`, `U-05`. Decisions are `ADR-NNNN`. Never number a decision `D-NN`; that is a diphthong rule.

### The corpus is the test suite

- Write a row's expected `Glyphs` from the spec, **not** by copying the engine's output. Otherwise the test can only agree with the engine.
- Every rule a row cites must exist and must fire. Every adopted or provisional rule must be cited somewhere (`tests/test_coverage.py`).
- Two different Shavian spellings may only give the same glyphs where the spec declares an identity (`tests/test_identities.py`).
- See `corpus/README.md` for the three table formats.

### The mode never knows code points

`s2t/mode.py` emits glyph names. Only `s2t/encodings/` knows code points. The engine's tables are checked against the spec's tables (`tests/test_spec_tables.py`, `tests/test_encoding.py`), so edit both together.

### Generated files

| File | Generated by | Guard |
|---|---|---|
| `corpus/review.html` (Alcarin), `corpus/review-NAME.html` (each other encoding) | `npm run corpus` | `tests/test_review_sheet.py` fails if one is stale or missing |
| `corpus/review.pdf`, `corpus/review-NAME.pdf`, `docs/*.pdf` | `npm run pdf` | none |

- After any corpus or engine change, run `npm run corpus` and commit every `review*.html` with it.
- **Do not regenerate the PDFs.** Alex builds them locally, where the three fonts are installed. If you edit `docs/language-guide.md` or `docs/philosophy.md`, add a task saying the PDF needs a rebuild.
- Never commit a local font path into `review.html`. Use `npm run corpus:view` for a local copy in `.tmp/`.

## Commands

```bash
npm test                                   # python3 -m unittest discover -s tests -t .
python3 shavian2tengwar.py "𐑢𐑦𐑯𐑑𐑼"         # convert (also reads stdin)
python3 shavian2tengwar.py --format literal "𐑞 𐑚𐑸𐑛"   # glyph names, for tecendil.com
python3 shavian2tengwar.py --inspect "𐑢𐑦𐑯𐑑𐑼"         # each step and the rules that fired
npm run corpus                             # regenerate corpus/review.html and review-freemono.html
npm run fmt                                # ruff format (run before every commit)
npm run lint                               # ruff check + format check, as CI runs them
npm run setup:docs && npm run pdf          # PDFs (Alex only; needs Chrome and the fonts)
```

`python3` must be 3.14 or newer (`python3 --version`). Older versions stop with a one-line message. On macOS: `/opt/homebrew/bin/python3.14`.

Run `npm run setup:dev` once to get ruff (pinned in `pyproject.toml`, dependency group `dev`). CI runs the tests, `ruff check` and `ruff format --check`; all three must pass. Don't claim they pass unless you ran them.

## Conventions

- **Python:** formatted by `ruff format`, no exceptions and no hand alignment. 3.14 idioms (`type` aliases, `X | None`, builtin generics, slotted frozen dataclasses). Standard library only in `s2t/`, `tests/` and the CLI. Line length 120. A pure reformatting commit goes in `.git-blame-ignore-revs`.
- **Formatting:** `.prettierrc` uses tabs and width 120 for JSON and Markdown.
- **Prose:** plain, short sentences. Name glyphs as `{tinco}` and marks as `[dot-above]` (Tecendil literals). Cite rule IDs.
- **Commits:** one logical change per commit, message in the imperative. Each commit leaves `npm test` passing. A commit that changes a rule names the rule ID.
- **Branches:** `main` is the release branch; work happens on branches and is merged after Alex reviews it.
