# ADR-0007: The Corpus Is the Test Suite

**Status:** Active
**Date:** 2026-10-11
**Affected:** corpus/, tools/corpus.py, tools/render_corpus.py, tests/, package.json
**Origin:** DECISIONS.md D-06, D-07, D-08, D-17, D-19
**Review:** Approved by merging PR #1
**Revert:** format and harness `fe2ee13`, `b5a27f3`; review sheet `2f2dfd7`; legacy tests `fe59b74` (the restored files fail against the new engine); font path `b8b84a0`; parser move `4e74f64`

## Context

The old tests were JSON manifests (`test_cases.json`, `test_cases_everson.json`) run by
`test_runner.py`, plus `test_collisions.py`. They tested CSUR and Everson output the engine no longer
produces, and they could not be read in review. Marks that land in the wrong place can only be judged
by looking at rendered Tengwar.

## Decision

- **`corpus/*.md` are Markdown tables** that are both documentation and tests. Three formats, told
  apart by header: a *case* (Shavian, English, IPA, Glyphs, Rules), a *same* pair (declared identity)
  and a *distinct* pair (under a heading containing "Distinct"). `corpus/README.md` documents them.
- **Citations are checked.** A case fails if a rule it cites does not exist in the spec or did not fire.
  `tests/test_coverage.py` fails if an adopted or provisional rule has no case (constraints P-01 to
  P-05 and R-02 are exempt; R-02 and P-04 are checked directly).
- **Expected glyphs are written from the spec, not copied from the engine.** The first version was
  generated by a throwaway script and audited row by row; from then on the Markdown is the source.
- **The legacy tests are retired.** `tests/test_identities.py` replaces the collisions test with the
  stricter rule that only declared identities may collide.
- **`corpus/review.html` is committed** and `tests/test_review_sheet.py` fails if it is stale. Regenerate
  with `npm run corpus`.
- **The committed sheet embeds no font path.** It asks for the installed "Alcarin Tengwar" by name.
  `npm run corpus:view` writes a copy with a local font file to `.tmp/review.html`, which is not
  committed.
- **The parser lives in `tools/corpus.py`**, because `tools/render_corpus.py` must not import from
  `tests/`. `tools/` is a package.

## Consequences

- The corpus can be read and reviewed on GitHub without running anything.
- Every corpus change also changes `review.html`, which makes a noisy diff. Dropping the file and the
  test and generating on demand is the alternative if that becomes a nuisance.
- Why the installed variable font is not always picked up by name on Alex's machine is unexplained.
